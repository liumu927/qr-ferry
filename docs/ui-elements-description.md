# 参考截图元素描述

> 目标：描述参考截图中看到的元素。
> 截图：qr-ferry 桌面端浅色主题「发送」页面。

## 窗口标题栏

- 左侧：`qr-ferry`
- 副标题：`光学二维码搬运 - v0.1.21`
- 选项卡：`发送`（选中）、`接收`
- 右上角图标：`?` 使用说明、月亮主题切换、最小化、最大化、关闭

## 左侧「内容」卡片

- 分区标题：`内容`
- 分段选择：`文件`（选中）、`文本`
- 文件状态：`(未选择)`
- 操作按钮：`选择`
- 复选框：`允许有损优化（会改变接收文件）`

## 左侧「参数」区

- 分区标题：`参数`，右侧带信息图标
- 参数项（两列）：
  - `频率`：`12`
  - `码制`：`标准QR（推荐）`
  - `纠错`：`L`
  - `帧长`：`1200`
  - `冗余`：`1.5`
  - `网格`：`1×1`
- 补发区域：
  - 标签：`补发帧数`
  - 数值：`50`
  - 按钮：`补发`

## 左侧「操作」区

- 分区标题：`操作`
- 主按钮：`开始发送`（蓝色，带发送图标）

## 右侧「发送预览」卡片

- 标题：`发送预览`
- 状态徽标：`待发送`
- 主内容区：占位文字 `(待发送)`

## 视觉风格与布局

- 整体为浅色主题，背景为浅灰白色。
- 主内容区由左右两张白色圆角卡片组成。
- 左侧卡片固定宽度，包含内容、参数、操作三个分区，分区之间用细分隔线隔开。
- 右侧卡片占据剩余空间，上方为标题和状态徽标，下方为大面积预览区。
- 主操作按钮 `开始发送` 使用蓝色填充，白色文字，带发送图标。
- 次要按钮（`选择`、`补发`）使用白底描边样式。
- 选中态（如 `文件` 分段、`发送` 选项卡）使用蓝色高亮。
